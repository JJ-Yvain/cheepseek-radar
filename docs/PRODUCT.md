# 产品定位 — CheepSeek Radar

> 本文回答「我们为谁、解决什么问题、不做什么」。功能与用法见根 `README.md`，技术细节见 `ARCHITECTURE.md`。

## 一句话

**CheepSeek Radar 是面向 AI 编码用户的模型套餐性价比雷达：把分散在各平台的订阅与按量报价，统一成「每 1 亿 token 价格」，并持续追踪变化。**

## 目标用户

| 用户 | 典型问题 |
|---|---|
| 个人开发者 / 独立开发者 | 「$10/月的 GOAT 和 $20/月的 Ollama Pro，哪个更划算？」 |
| 重度 Coding Plan 用户 | 「我每月大约用 5 亿 token，订阅还是按量？」 |
| 小团队技术负责人 | 「团队统一采购哪一档？额度够不够？」 |
| 价格敏感的内容创作者 / 社区用户 | 「最近哪家调价了？给我一张能直接发的榜单。」 |

## 核心场景

1. **新套餐 / 调价出现**：快速判断它相对现有渠道的位置，而不是被「月费低」「额度高」单独误导。
2. **已有订阅复盘**：缓存读取 / 普通输入 / 模型输出占比、峰谷比例变化后，重新算一次每亿价与回本点。
3. **同平台跨版本比较**：例如 OpenCode 的 DeepSeek 历史线与 1017 额度不同，必须按各自 quota 折算。
4. **内容输出**：把榜单 / 对比结果导出为 3:4 图文卡或海报，直接发布。

## 价值主张

- **一个口径**：月费、额度、峰谷、缓存统一折算，不用自己拿计算器拼公式。
- **一条时间线**：每次抓取生成快照，涨跌自动标记；历史只追加，能回看「当时为什么这么排」。
- **一眼看懂**：头页榜单按性价比排名，价格条呈现实力差距；点开任意条目看完整画像。
- **一切可核对**：每条价格带来源 URL、抓取日期与备注；口径参数在面板上明示且可调。
- **研究沉淀**：把一次性的价格观察写成可追溯的报告；草稿仅在本地预览，确认后才进入公开构建。
- **本地优先**：数据留在本机 SQLite，不上传、不依赖云服务。

## 核心概念

| 概念 | 定义 |
|---|---|
| **快照** | 某一天对「平台 × 模型 × 套餐」的一次价格记录；同一监测项再次录入即新增快照 |
| **监测项** | 「平台 × 模型 × 套餐」的唯一组合；快照按监测项串成时间线 |
| **每亿价** | 按当前使用画像折算出的每 1 亿 token 等效价；订阅渠道按实际月费口径 |
| **总额度** | 月额度可换取的 token 量（亿/月），随算法参数联动 |
| **回本点** | 月费 ÷ 按量每亿价；低于该用量时按量更便宜 |
| **使用画像** | 缓存命中率、峰谷配比、输入输出比例 |
| **模型级额度** | 部分平台按模型线给额度（如 OpenCode 历史线 $30~$60 vs 1017 $100），不是套餐总 credit |

## 产品原则

1. **口径透明**：公式、默认参数、假设全部可见；不把估算包装成账单。
2. **数据可追溯**：每个价格必须有来源与日期；未核实的促销不写成事实。
3. **历史不可变**：已录入的快照不覆盖；调价通过新增快照表达。
4. **本地优先、零依赖**：不引入账号体系、云存储与第三方运行时。
5. **聚焦 DeepSeek**：优先保证 DeepSeek 主要渠道的价格覆盖与口径准确性。
6. **克制表达**：不使用夸张标题与焦虑式营销；结论必须能被数据复算。

## 非目标

- **不做模型代理 / API 转售**：产品只做价格信息与决策辅助。
- **不做实时账单系统**：输出是基于公开报价与使用画像的估算，不是平台结算单。
- **不做模型能力 / 质量评测**：性价比只覆盖价格维度。
- **不做全自动全网爬虫**：当前采用半自动巡检（抓取 → 核验 → 人工确认 → 入库），优先保证数据正确。
- **不做多租户 SaaS**：当前形态是本地单用户工具。

## 体验原则

- **打开即答案**：首屏先给榜单结论，再给明细。
- **每个数字能解释**：点击条目可看到输入、缓存、输出、峰谷与额度来源。
- **不隐藏假设**：内置三组计算画像（95/4/1、97/2.5/0.5、98/1.6/0.4）与可调参数并列展示，用户知道自己在看什么。
- **失败要明确**：抓取解析失败时报告「规则失效」，不写入猜测数据。

## 成功标准

| 维度 | 标准 |
|---|---|
| 数据新鲜度 | DeepSeek 核心渠道至少月级更新；促销敏感期加密 |
| 覆盖度 | DeepSeek 主要 Coding Plan 渠道覆盖完整 |
| 可信度 | 每条价格有来源 URL 与抓取日期；变更可 diff |
| 可用性 | 非开发者 3 分钟内看懂榜单与回本点 |
| 可协作性 | 新平台可通过清晰的适配规则接入；数据修正有固定流程 |

## 品牌

- **名称**：CheepSeek Radar（中文副标题：模型套餐性价比雷达）。
- **语气**：事实、克制、可复算；避免「最便宜」「吊打」等绝对化表述。
- **视觉**：青铜 `#7d5c2c` + 象牙白 `#faf8f2` + 石板青 `#3f5d55`；暖纸底、衬线正文、数字右对齐。
- **署名**：导出图默认署产品名，可通过配置改为个人 IP。
