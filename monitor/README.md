# CheepSeek Radar · 监控台操作手册

> 产品总览见 `..\README.md`；定价口径与架构见 `..\docs\ARCHITECTURE.md`；数据源规则见 `..\docs\DATA-SOURCES.md`。
> 当前覆盖（2026-11-02）：**4 平台 / 3 条模型线 / 15 条快照 / 11 个监测项**——DeepSeek 官方 API、Command Code、OpenCode、Ollama。

用一张 SQLite 快照表持续记录各平台 × 模型 × 套餐的价格与额度，支持定期巡检、变化对比与榜单查看。零依赖（Python 标准库 `sqlite3`），数据库 `plans.db`，CLI `monitor.py`，Web 面板 `panel.html`。

## 快速使用

### ① 日常使用：双击 `打开监控台.vbs`（推荐）

静默启动（**无控制台窗口、不占任务栏**）→ 自动打开浏览器。重复双击不会叠加实例（检测到已运行则直接打开浏览器）。

**生命周期（心跳保活）**：面板页面每 30 秒静默 ping 一次服务，因此——

- **只要面板页面还开在浏览器里**（哪怕切到别的标签页、最小化、看别的网页）→ 服务**保持运行**；
- **关闭该页面**（或整个浏览器）→ 心跳停止 → **5 分钟后服务自动退出**；
- 也可点面板右下角「停止服务」立即退出。

### ② 命令行启动（与双击等效）

```bash
# --idle-exit 分钟 = 心跳停止后多久自动退出，0 = 永不自动退出
python server.py --port 8765 --open --idle-exit 5
# → 打开 http://127.0.0.1:8765/
```

> 注：直接命令行启动时不会自动心跳（心跳由面板页面发起），此时 `--idle-exit` 按「无任何请求」计时。

### ③ 命令行录入 / 查看

```bash
# 巡检录入（核对完页面后调用）
python monitor.py add --date 2026-11-02 --platform Ollama --plan Pro \
      --model deepseek-v4.1-flash-1017 --fee 20 --quota 60 --window "月重置" \
      --in 0.15 --cache 0.003 --out 0.6 --in-p 0.3 --cache-p 0.006 --out-p 1.2 \
      --url https://ollama.com/pricing

python monitor.py latest          # 最新状态表
python monitor.py diff            # 对比最近两轮快照，自动报变化
python monitor.py history --platform opencode
python monitor.py dump -o snapshots_export.csv
```

`启动监控台.bat` —— **诊断模式**（保留控制台窗口、显示运行日志）。
日常不需要；仅当 vbs 启动异常时用它排查（关闭窗口即停止服务）。

## 自动抓取（巡检用）

```bash
python monitor.py fetch --platform ollama --with-prev
python monitor.py fetch --platform opencode --with-prev
python monitor.py fetch --platform commandcode --with-prev
```

自动抓取权威源页面并跑**多维核验**（双通道解析交叉比对 + 价格合理性〔正数 / 峰 ≥ 谷 / 字段完整〕+ 与库内最近快照偏差告警〔> ±30%〕+ 促销变化提示），**只输出核验通过的草稿、不写库**。

流程：抓取 → 核对草稿与页面原文 → 人工确认 → `add` 或面板录入。页面结构变化导致解析失败时明确报「规则失效」，不会写入错误数据。

> **未覆盖的平台**：官方 API 尚无解析器，巡检时直接抓页面、人工核对后录入。
> 已移除的平台：flatkey / inferx / B.AI（2026-11-02 起停止跟踪，抓取器与活动库数据已清除；清理前备份仍含旧数据，见 `..\HANDOFF.md` §七-7）。
> 模型范围：2026-11-03 起只跟踪 DeepSeek 模型线；GLM 数据已从活动库移除（删除前备份仍含旧数据）。

## Web 面板

顶部导航为「榜单 / 数据台 / 报告」：前两者是页内锚点，报告进入 `/reports/` 的静态报告页（本地预览由服务自动构建）。

### 头页（封面榜单）与导出

- **头页**：打开面板首先看到——大标题「哪家最划算」+ **按排名分面积的错落网格**（① 冠军跨两行最大格 / ② 跨两列横块 / ③④ 小方 / 右侧速览栏通高，四格铺满）+ **对数刻度价格条**直观呈现差距；**官方直充以虚线「基准格」虚化呈现**。
  顶部吸顶品牌条含期号与「↓ 数据台」锚点；模型 chips 切换榜单维度（默认 `deepseek-v4.1-flash-1017`），点任一格打开该条目图文卡；**参数 / 币种改动与下方数据台实时同步**。
- **算法口径带**（网格下方通栏）：讲清「每亿价怎么算出来的」——缓存命中 / 峰谷配比 / 输入输出 / token 构成 4 项，**与面板参数实时联动**。
- **3:4 导出**：头页品牌条「存为图片」→ 预览弹窗 → 存 PNG（`hero-card` 480×640，导出 1440×1920），同版式响应式重排。
- **海报** `poster.html`（独立文件，零依赖）：3:4 自媒体封面（720×960，导出 2× = 1440×1920），含「保存为图片」按钮；色系与面板一致，署名可配置。
- **配色样张**：已移入 `archive\设计留档\`，非日常文件。

### 数据台

- 查看全部快照（**平台 / 模型 / 套餐多选筛选**，套餐自动联动为所选平台的二级选项，选项旁显示记录数）
- **「生成对比」**：选两个渠道生成 3:4 竖版对比卡；**单条图文卡**点击表格任意行弹出
- **「最新情况」一键筛选**：只显示每个监测项最新一次抓取，数据不删除、变化对比保留；再点恢复全部历史
- **变化列**：按「平台 + 套餐 + 模型系列」对比同一系列上一轮快照；当前配置的系列规则覆盖 DeepSeek Flash（`0731` / `09-10` / `1017` 等），未知模型退回精确模型名。只比较当前画像下的每亿价，跨代际会标「较上代」，悬浮可看基准模型、日期与前后价格。
- 表头点击排序；总额度列（月额度折算成 token 量，亿 tokens）
- 新增 / 编辑 / 删除；计算画像可调（预设 / 缓存读取 / 普通输入 / 模型输出 / 峰谷 / 币种 / 汇率）
- **单卡 / 双卡弹窗**：内嵌画像参数条，默认继承数据台当前参数；卡内切换预设或自定义会实时重算，关闭后不影响全局；支持「恢复初始」。卡片算法区为「当前画像 + 参考画像」：当前跟随卡内参数，参考在当前为默认时取高缓存、否则取默认。
- 价格列合并显示最低价（谷价），hover 弹出完整矩阵
- 与上一轮 / 上代快照自动对比（涨 ▲ 红 / 跌 ▼ 绿）；CSV 导出

API：`GET/POST /api/snapshots`、`PUT/DELETE /api/snapshots/<id>`、`GET/POST /api/templates`、`PUT/DELETE /api/templates/<id>`、`GET /api/meta`（详见 `server.py` 头注释）。

## 数据约定

- **一行 = 一次抓取的「平台 × 模型 × 套餐」快照**；同一监测项再次录入即产生新快照，diff 自动对比最近两轮。
- 价格为**每百万 token**；默认 USD，官方直售为 CNY（`--currency` 指定）。
- 峰谷双价分列：`--in/--cache/--out` 为谷价，`--in-p/--cache-p/--out-p` 为峰价；无峰谷的平台只录谷价列。
- `--fee` 月费、`--quota` 月额度（订阅买额度型才有）；`--window` 记窗口限制。
- **窗口限制为计划 / 模型级**（以页面原文为准）：
  - Command Code GOAT = 计划窗口 `5h $20 / 7d $50 / 月 $100`（DS 1017 模型级额度 $100；历史线 $60）；
  - OpenCode Go = 按模型月额度推算（5h = 20%、周 = 50%、月 = 100%）：DS 1017 月 $100 → `5h $20 / 7d $50 / 月 $100`；历史线按各自额度（$30 / $60）推算；
  - Ollama Pro = `月重置`（无 5h/周限制）；官方 API 按量无窗口，留空。
- **CC / OC 的 quota 是模型级月度额度，且随模型线不同**（不是套餐总 credit）：
  - CC GOAT：DS 1017 **$100**、历史线 $60；
  - OC Go：DS 1017 **$100**、历史线 $30~$60；
  - Ollama Pro：**$60 账户共享 credits**，不是 per-model。
  录入时按页面原文；跨代际 / 跨平台对比前先核对 quota，**不能默认所有模型线同额**。
- **OC 促销**：营销页仍有「New DeepSeek V4.1 Flash gets 4× usage limits for a limited time」横幅且未标结束；docs 列 $100。当前按 $100 录入，**`promo` 字段留空**——避免封面卡显示未核实的「限时 4 倍额度」标语（4× 若以旧 $15 为基数应为 $60，与 $100 对不上；$100 是否为 4× 后的值仍待核实，已写进 note）。若后续确认促销状态 / 回落，补录新快照（不改历史行）。
- **`fetch` 只抓价表，不采 window / per-model quota**：window 与 CC / OC 的模型级额度需人工按页面表格核实后随 `add` / 面板补录（勿靠页面抓取）。注意 CC 的 Monthly credits 表是纯文本行（无模型链接），部分模型条目不会自动出现在 fetch 草稿里，需人工核对。
- 价表 = 上游直通（GOAT / OpenCode 无独立价）时价格列留空，`--note` 注明。
- 测试隔离：`MONITOR_DB=/path/to/tmp.db python monitor.py ...` 可在临时库上演练。

## 巡检工作流（半自动）

1. **触发**：按关注清单定期巡检，或发现调价消息时立即巡检。
2. **抓取**：`fetch` 抓目标页面并核验（规则见 `..\docs\DATA-SOURCES.md`）。
3. **录入**：`monitor.py add` 逐条录入本次快照（同一监测项）。
4. **对比**：`monitor.py diff` 自动报变化 → 有变化再复核口径并记录。
5. **查看**：每亿价与排名直接在面板调参查看；需要发布时用图文卡 / 海报 / CSV 导出。

## 已知口径坑

- Ollama 2026-08 前的 GPU 时间计价（¥1.3/亿、~101 亿/月反推）已随商业模式变更**作废**，勿与新快照混比。
- **OC 的 $100 可能是 4× 促销值**：营销页横幅未标结束；若按标准值约 $25 估算，每亿价约 ¥6.3，而不是 ¥1.58。引用排名前先核实促销状态。
- **额度随模型线变化，不能默认 $100**：CC/OC 历史线为 $30~$60，1017 为 $100；Ollama 的 $60 是账户共享 credits，不是 per-model。跨代际比较前先核对各自 quota。
- **CC 未显式标 1017**：页面写 "DeepSeek V4.1 Flash (latest)"、发布日期 09-10；当前按最新 Flash 线录入，价格与 1017 相同，版本口径待平台确认。
- 官网价直售为人民币，其他平台为美元——对比每亿价时先统一币种（面板默认汇率 6.65，2026-11-02 市场参考；可调）。
- **限时额度不是常态价**：CC / OC 的额度带促销期限，**到期 / 回落后必须补录新快照**（不改历史行），否则面板会拿过期额度算每亿价。
- **促销的「生效日」要写进 promo 文本**（如 `限时10%（09-12起）`）——面板 `promoState()` 靠它区分「促销预约 / 促销中」，写错会被读成已生效。
- **Ollama 价表结构已变**：无后缀行 = 峰价、`(Off-Peak)` 行 = 谷价；`fetch_ollama` 已按此解析，页面再改版会报「规则失效」。
- **历史模型线**：`deepseek-v4-flash-0731` 与 `deepseek-v4.1-flash` 是历史数据，只追加不覆盖；当前线是 `deepseek-v4.1-flash-1017`，看榜时注意模型 chip。
